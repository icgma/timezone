# timezone — 时区换算

外媒稿件里的发布时间，换算到本地。含夏令时判断，可同时比对多个新闻中心。

**在线使用:** https://icgma.github.io/timezone/

## 解决什么问题

路透社标注 `14:30 GMT` 发的稿，北京时间是几点？跨季度翻旧稿时，那个时间点当地是不是夏令时？
手算容易错，尤其是夏令时切换的那两天。

## 支持的输入格式

| 输入 | 识别为 |
|---|---|
| `2026-07-27 14:30` | 墙上时间，按所选来源时区解释 |
| `14:30` | 今天的这个时刻（来源时区） |
| `1753626600` | Unix 时间戳（秒，绝对时刻） |
| `2026-07-27T14:30Z` | 带偏移的 ISO 8601（绝对时刻，不受来源时区影响） |

输入框留空时跟随当前时间，每秒走字。

## 夏令时处理

夏令时切换会产生两种边界情况，本工具都会明确提示而不是静默给个可能错的答案：

- **不存在的时间**：春季前拨跳过一小时（如纽约 3 月某日 02:30 不存在），标注"夏令时缺口"
- **重复的时间**：秋季回拨使某小时出现两次，标注"时间有歧义"，取先出现的那次

时区数据来自浏览器内置的 `Intl` API，随系统更新，无需维护字表。

## 技术说明

- 时间数学独立在 `tzmath.js`，纯函数、无 DOM 依赖，可直接用 node 测试
- `node test.js` 运行 40 个断言，覆盖夏令时边界、跨日、闰年、真实换算场景
- 无构建、无依赖、纯静态

```sh
node test.js   # 运行测试
```

## 本地运行

直接用浏览器打开 `index.html` 即可。
